# Cybersecurity Homelab

## Overview

This project documents a cybersecurity homelab built using Oracle VirtualBox, Kali Linux, and Ubuntu Server. The lab was designed to develop hands-on skills in networking, Linux administration, reconnaissance, SSH remote access, and password auditing.

## Objectives

- Learn virtualization concepts
- Configure Linux systems
- Practice network reconnaissance using Nmap
- Establish secure remote administration using SSH
- Perform password auditing with John the Ripper
- Document findings and security observations

## Technologies Used

- Oracle VirtualBox
- Kali Linux
- Ubuntu Server
- Nmap
- OpenSSH
- OpenSSL
- John the Ripper

## Key Accomplishments

- Configured bridged networking between Kali and Ubuntu
- Identified services using Nmap
- Established SSH connectivity to Ubuntu Server
- Generated SHA-512 password hashes
- Recovered a weak test password through a dictionary attack using John the Ripper
